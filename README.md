# 地图数据存储项目

这是一个全面的地理信息数据存储项目，包含了世界各国和中国各级行政区域的地理数据和GeoJSON格式的地图数据。

## 项目概述

本项目旨在提供一个结构化的地理数据存储解决方案，涵盖全球国家和地区信息以及中国详细的行政区划数据。数据以JSON和GeoJSON格式存储，便于在Web应用、地图可视化和数据分析项目中使用。

## 数据结构

### 核心数据文件

#### 1. 世界地图数据存储.json
- **内容**: 全球254个国家和地区的完整信息
- **数据字段**:
  - `id`: 唯一标识符
  - `chinese`: 中文名称
  - `english`: 英文名称
  - `iso2`: ISO 3166-1 alpha-2 国家代码
  - `iso3`: ISO 3166-1 alpha-3 国家代码
  - `center`: 地理中心坐标 [经度, 纬度]
  - `sort`: 排序序号
  - `createTime`: 创建时间戳
  - `updateTime`: 更新时间戳

#### 2. 中国省份.json
- **内容**: 中国所有行政区划的层级数据
- **记录数量**: 28,939+ 条记录
- **数据层级**: 省/直辖市 → 市/州 → 区/县 → 街道/镇
- **数据字段**:
  - `areaCode`: 6位行政区划代码
  - `areaName`: 区域中文名称
  - `level`: 行政级别 (province/city/district/street)
  - `parentCode`: 上级区域代码
  - `center`: 地理中心坐标 [经度, 纬度]

### 映射和翻译文件

#### world/world-mapping.json
- 国家英文名称到中文名称和GeoJSON文件名的映射关系
- 提供统一的命名规范

#### world/zh.js
- JavaScript模块格式的国家名称中英文对照表
- 便于前端应用直接引用

#### world/world.json
- 世界国家数据的备份或简化版本

### GeoJSON地图数据

#### world/geojson/ 目录
包含两类GeoJSON文件：

1. **中国行政区划地图**
   - 文件命名: `{6位区域代码}.json` (如 `110000.json` 代表北京市)
   - 包含详细的行政区边界几何数据
   - 支持省、市、区县级别的地图展示

2. **世界各国地图**
   - 文件命名: `{国家英文名}.json` (如 `China.json`, `Japan.json`)
   - 包含国家边界的完整几何信息
   - 支持全球地图可视化需求

#### GeoJSON数据格式
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature", 
      "properties": {
        "adcode": "行政区代码",
        "name": "区域名称",
        "center": [经度, 纬度],
        "level": "行政级别",
        "parent": {"adcode": "上级区域代码"}
      },
      "geometry": {
        "type": "MultiPolygon|Polygon",
        "coordinates": "边界坐标数组"
      }
    }
  ]
}
```

## 使用场景

### 1. Web地图应用
- 提供国家和地区选择功能
- 支持多级联动的地址选择器
- 地图可视化和区域展示

### 2. 数据分析
- 地理数据分析和统计
- 区域经济指标可视化
- 人口分布和密度分析

### 3. 国际化应用
- 多语言地区名称支持
- 国际标准代码对照
- 跨国业务数据处理

### 4. 政府和企业应用
- 行政区划管理系统
- 物流配送区域划分
- 市场分析和业务拓展规划

## 技术特点

### 数据标准化
- 遵循ISO 3166国际标准
- 统一的坐标系统 (WGS84)
- 标准化的数据格式和命名规范

### 完整性
- 覆盖全球254个国家和地区
- 中国行政区划数据完整到街道级别
- 包含地理中心点坐标信息

### 易用性
- 多种数据格式支持 (JSON, GeoJSON, JavaScript)
- 清晰的文件组织结构
- 丰富的元数据信息

## 数据更新

- `createTime` 和 `updateTime` 字段记录数据的创建和更新时间
- 支持增量更新和版本控制
- 定期维护确保数据准确性
